# Images Bridge

Load canonical truth from:

- `.agent/rules/foundation-design-system.md`
- `.agent/rules/foundation-accessibility.md`

Use this bridge only to focus the audit:

- Check dimensions, loading priority, and alt-text correctness before aesthetic comments.
- Audit CLS risk and theme/media integration together; image polish is often a layout issue here, not just an asset issue.
- If the component uses a shared image primitive, verify the primitive contract before recommending local fixes.
