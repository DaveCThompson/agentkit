## Source-of-truth map
- **`.agent/` (singular) is the source.** `.claude/ .agents/ .gemini/ .opencode/` are GENERATED by
  `agentkit sync` — edit the source and re-sync, never hand-edit a mirror (a hand-edited mirror is
  drift, caught by `agentkit check`). (`.agents/` plural = Codex's generated skill surface, beside
  `.agent/` — the source is the one without the `s`.)
- Kit intent lives in `.agentkit.json`; shipped state in `.agentkit.lock` (committed, machine-written
  — do not edit).
- Docs use the four-dir model: `docs/{knowledge-base,working,backlog,archive/YYYY-MM}`.
  KB = what IS true · CHANGELOG = what WAS done · working = what's IN FLIGHT · archive = what's
  FINISHED (out of default search via the repo-root `.ignore`). See
  `docs/knowledge-base/overview/docs-structure-convention.md`.
