# Knowledge base

This directory is a project-local extension point. The public kit tracks this
index only; application specifications, research corpora, and ticket history
belong in the consuming project and remain outside this distribution repository.

## Use the kit's public sources

- [Governance](../../governance/README.md) contains the kit's reusable contracts and decisions.
- [The docs convention](../README.md) defines the four-directory project layout.
- [`.agent/`](../../.agent/) is the canonical source for agent assets.

When a project uses `agentkit`, keep its durable project truth in that project's
`docs/knowledge-base/` and keep private material out of the public kit clone.
