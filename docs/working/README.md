# Working documents

This directory holds project-local plans, reviews and active tickets. Detailed working state is
Git-ignored in this distribution repository. Public guidance must not depend on those local files.

Read README.local.md in this directory when present for the local work index. It preserves links
to active tickets, reviews and evidence; status stays in each work item. Its absence in a fresh
clone is expected. Do not publish it or its targets merely to make public links resolve.

See [the docs convention](../README.md) and [the governance index](../../governance/README.md)
for the shared rules.
